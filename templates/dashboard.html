Información del modelo

El sistema utiliza el algoritmo Random Forest para estimar la demanda de productos de comida rápida. El modelo considera el producto, el día de la semana, el día del mes, las ventas del día anterior, las ventas de hace siete días y el promedio de ventas de los últimos siete días.

El modelo fue entrenado con datos sintéticos para fines académicos. Las predicciones son experimentales y todavía no han sido validadas con ventas reales del negocio.
